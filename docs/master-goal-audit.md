## Evidence rules

- Implemented means a current code path exists; it does not imply installation in the captain's daily app or production deployment.
- Local verification uses isolated projects and profiles. Synthetic provider/GitHub responses prove handling of those responses, not a working authenticated remote journey.
- Live provider evidence below proves the particular task recorded. It does not prove later code changes were exercised by the same live run.
- Optional integrations are adopted only for a demonstrated useful capability. A decision to defer an optional vendor is not a fake integration or proof that the corresponding product capability is implemented.
- Human review, acceptance, merge and publication remain distinct from a finished provider turn.
