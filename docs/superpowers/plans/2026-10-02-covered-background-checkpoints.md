Before capturing another full profile, skip that slot only when startup recovery has completed, the dirty generation equals the saved generation, persistence health is saved, no storage error/uncertainty or shutdown is present, and the last published receipt has the queue's current epoch and sequence. Return that existing receipt; never invent a new receipt or call persistenceSaved for the skip. Only background entries queued behind an active operation qualify. Explicit validation and every required barrier retain their existing write/receipt behavior.
