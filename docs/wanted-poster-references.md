# Wanted poster references — 2026-11-07

The poster composition follows the manga's oversized serif WANTED, rectangular portrait, DEAD OR ALIVE, name, prominent reward and small MARINE footer. These are Sunny adaptations with character portraits, not exact reproductions of every canon photograph (notably Luffy and Franky).

Research: [official updated poster release](https://one-piece.com/news/65548/index.html), [manga poster gallery](https://onepiece.fandom.com/wiki/Bounty/Gallery), and [official character directory](https://one-piece.com/character/index.html). The official pages returned search-index contents; direct page retrieval was blocked with HTTP 403. Image search supplied visual poster references; no reference images were downloaded into the app.

Official directory amounts in Berries: Luffy 3,000,000,000; Zoro 1,111,000,000; Nami 366,000,000; Usopp 500,000,000; Sanji 1,032,000,000; Chopper 1,000; Robin 930,000,000; Franky 394,000,000; Brook 383,000,000; Jinbe 1,100,000,000. These are story data, never task metrics or monetary app balances.

[Law](https://one-piece.com/character/law/index.html): 3,000,000,000. [Ace](https://one-piece.com/character/ace/): 550,000,000, explicitly presented as last known bounty. [Vivi](https://one-piece.com/character/Nefeltari_Vivi/index.html) and [Perona](https://one-piece.com/character/Perona/index.html) have no amount in their official profiles: display UNKNOWN / BOUNTY NOT PUBLISHED, never invent a value. Their shared wanted-paper composition is an app adaptation.

Core portraits use a close rectangular CSS crop inside each original atlas cell, removing the baked circular perimeter from view without altering the shared avatar sheet. New ally portraits use a dedicated 2×2 atlas; original pixel sprites and animation contracts are untouched. Bounty text remains readable DOM text with Berries labels. Native profile controls, reduced motion and real delegation events are unchanged.
