2026-11-07 poster refinement: Alfa Slab One Regular (Alfa Slab One Project Authors) and IM Fell English Roman (Igino Marini) downloaded unmodified from google/fonts/ofl/alfaslabone and google/fonts/ofl/imfellenglish. Both use SIL OFL 1.1, retained as AlfaSlabOne-OFL.txt and IMFellEnglish-OFL.txt. These are licensed typographic approximations, not a verified official anime font. Alfa Slab One supplies the heavy display masthead; IM Fell supplies irregular printed names, numbers and small footer type. Fonts load locally in packaged file:// pages.
